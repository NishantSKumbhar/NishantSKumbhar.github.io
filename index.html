06 / HOW I THINK

Beyond “it works on my machine”

Quality bar
Production mindset

01. Clear responsibilities

Maintainability

Keep controllers thin, place business decisions in the appropriate layer, and make dependencies explicit through dependency injection.

02. Data access with intent

Performance & correctness

Choose EF Core or Dapper based on the query and team needs—not fashion. Inspect SQL, avoid N+1 patterns, use appropriate indexes, and paginate large result sets.

03. Fail safely and observably

Reliability & security

Validate input at the boundary, avoid leaking internal exception details, log useful context without secrets or sensitive data, and return consistent API responses.

04. Measure, then improve

Evidence over guesswork

Use baselines and repeatable measurements to identify bottlenecks. An optimization is only valuable when correctness remains intact and the improvement can be demonstrated.
